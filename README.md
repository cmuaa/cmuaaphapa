# ผ้าป่าการกุศลเพื่อทุนการศึกษา มช. 2569

หน้าเชิญร่วมบุญของสมาคมนักศึกษาเก่ามหาวิทยาลัยเชียงใหม่ โทนม่วง ทอง และงาช้าง รองรับมือถือและ GitHub Pages โดยไม่ต้องมีขั้นตอน build

## เปิดดู

เปิด `index.html` ในเบราว์เซอร์ได้ทันที หรือใช้ local web server เพื่อทดสอบการคัดลอกเลขบัญชี เช่น `python -m http.server 8792` แล้วเปิด `http://localhost:8792/`

## ไฟล์ที่แก้ได้

- `index.html`: ข้อความ วันงาน สถานที่ เลขบัญชี ช่องทางร่วมบุญ และช่องทางติดต่อ
- `styles.css`: สี ตัวอักษร ระยะห่าง และการแสดงผลบนมือถือ
- `script.js`: เมนูมือถือ แท็บร่วมบุญ คัดลอกเลขบัญชี และการเปิดภาพขนาดใหญ่
- `assets/images/`: โลโก้ ภาพกิจกรรม QR และโปสเตอร์
- `assets/phapa-2026.ics`: ไฟล์เพิ่มวันงานลงปฏิทิน ต้องแก้ตามเมื่อเปลี่ยนวันหรือเวลา

## เผยแพร่บน GitHub Pages

1. ตรวจไฟล์ที่เพิ่มใน GitHub Desktop แล้ว commit และ push ด้วยบัญชีที่มีสิทธิ์ใน repo
2. ที่ GitHub เปิด Settings > Pages
3. เลือก Deploy from a branch จาก branch ที่ push ไว้ และโฟลเดอร์ `/ (root)`
4. เมื่อเผยแพร่สำเร็จ URL ตาม remote ปัจจุบันคือ `https://cmuaa.github.io/phapa/`

ไฟล์ใช้ path แบบสัมพันธ์กัน จึงนำไปวางใต้โฟลเดอร์ของเว็บไซต์สมาคมฯ ได้ด้วย หากเปลี่ยน URL ให้ปรับ `og:url`, `og:image` ใน `index.html` และ `URL` ในไฟล์ปฏิทิน
